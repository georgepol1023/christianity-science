# christianity-science.gr — νέα αρχική σελίδα & αρχείο εκπομπών

## Δομή
```
index.html          Η νέα αρχική (hero, επόμενη εκπομπή, αρχείο, στήλη, βίντεο)
articles.html       Άρθρα ανά κατηγορία
material.html       Θέματα (κατηγορίες)
faq.html            Ερωτήσεις ακροατών
media.html          Συνεντεύξεις, δημοσκοπήσεις, βίντεο, βιβλία
links.html          Σύνδεσμοι
contact.html        Επικοινωνία
about.html          Ποιοι είμαστε
material/*.htm      Τα θέματα/μελέτες των εκπομπών, στο νέο σχέδιο (ίδια ονόματα με πριν)
categories/*.htm    Οι κατηγορίες θεμάτων, στο νέο σχέδιο
articles/*.htm      Οι κατηγορίες άρθρων, στο νέο σχέδιο
*.htm (ρίζα)        Παλιές διευθύνσεις (faq.htm κ.λπ.) που ανακατευθύνουν στις νέες σελίδες
css/site.css        Όλο το στυλ (φωτεινό/σκοτεινό θέμα, responsive, εκτύπωση)
js/broadcasts.js    ΤΑ ΔΕΔΟΜΕΝΑ: εκπομπές + ρυθμίσεις (το μόνο αρχείο που αλλάζετε συνήθως)
js/app.js           Λογική αρχικής: αναζήτηση, player, αντίστροφη μέτρηση
js/page.js          Λογική εσωτερικών σελίδων: θέμα, μενού, φίλτρα
files/              PDF και έγγραφα
pictures/           Εικόνες που χρησιμοποιούν τα κείμενα
mp3/                Όλα τα mp3 (εκπομπές, συνεντεύξεις, δημοσκοπήσεις)
```

## Εγκατάσταση
Ο φάκελος περιέχει ολόκληρο το site και δεν εξαρτάται από τον παλιό server.
Ανεβάστε όλο το περιεχόμενο στη ρίζα του site. Οι παλιές σελίδες αντικαθίστανται από τις νέες
με τα ίδια ονόματα, οπότε παλιοί σύνδεσμοι και αποτελέσματα αναζήτησης συνεχίζουν να δουλεύουν.

Τοπική προεπισκόπηση: `node tests/server.js` μέσα στον φάκελο και άνοιγμα του `http://127.0.0.1:8081/`.
Οι φάκελοι `tests/` και `tools/` δεν ανεβαίνουν στον server.

Μετά από αλλαγή σε `css/` ή `js/`: `python tools/stamp.py` (ανανεώνει το `?v=` ώστε οι browsers να πάρουν τη νέα έκδοση).
Έλεγχοι: δείτε το [tests/README.md](tests/README.md).

## Νέα εκπομπή
Στο `js/broadcasts.js`, στην κορυφή του τρέχοντος κύκλου:
```js
ep("2026-10-01", "Τίτλος εκπομπής", "Slug_arxeiou"),
```
Αν το αρχείο ξεκινά με `CS_` προσθέστε `{ cs: true }`. Αν έχει 3 ημίωρα, `{ parts: 3 }`.
Ενημερώστε επίσης `nextBroadcast` και `latestColumn` στο `SITE_CONFIG`.

## Δυνατότητες
- Ενιαίος player που μένει κάτω ενώ περιηγείστε, με αυτόματη συνέχεια στο επόμενο ημίωρο
- Θυμάται πού σταματήσατε σε κάθε ημίωρο ("Συνέχεια ακρόασης")
- Αναζήτηση χωρίς τόνους (γενεση = Γένεση), φίλτρο ανά κύκλο
- Ταχύτητα 0,75×–2×, ±15 δευτ., έλεγχος από οθόνη κλειδώματος κινητού
- Σύνδεσμος ανά εκπομπή (π.χ. `index.html#e-2026_09_17`)
- Αντίστροφη μέτρηση για τη ζωντανή εκπομπή + αρχείο ημερολογίου (.ics)
- Συντομεύσεις: `/` αναζήτηση, `Space` αναπαραγωγή/παύση, `←` `→` ±15 δευτ.
